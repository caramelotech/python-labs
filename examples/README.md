## Como usar

1. Escolha um exemplo implementado
2. Leia o README do exemplo
3. Entre na pasta do exemplo e execute com `python main.py`
4. Modifique, teste e experimente variações

Os exemplos usam apenas a biblioteca padrão, a menos que o README do exemplo diga o contrário.
